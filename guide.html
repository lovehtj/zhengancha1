一、这个 App 是干什么的

「证安查」是一款帮施工、监理企业管好证件的小工具。工地现场有三类证件必须有效、不能过期，一旦过期或失效就属于重大事故隐患，可能被处罚：

  • 特种作业人员证——电工、焊工、架子工、塔吊司机、高处作业等人员的证；
  • 安全生产许可证——企业施工的"营业执照"之一；
  • 安全生产管理人员证——安全员、项目负责人等人的证。

证安查把它们变成一件很轻的事：

  • 拍照就能录入：拍一张证件照，自动识别姓名、证号、工种、发证机关、有效期，不用手打；
  • 联网查真伪：一键连住建部 / 应急管理部官网，核对证件是否真实、是否在有效期内；
  • 到期自动提醒：快到期、已过期的证件，列表里用颜色标出来；
  • 多个工地分开管：一个 App 管好几个项目，切一下只看这个工地的人，互不干扰；
  • 一键导出：台账导成 Excel，上报、打印、迎检直接用。
一句话：拍照存证 · 联网验真 · 到期提醒 · 导出报表。

四、多个工程项目怎么管

一个 App 可以同时管好几个工地，台账彼此分开、互不干扰。先分清两个词：

  • 项目 = 工地。比如「滨江路项目」「中心医院项目」，是要分开管的；
  • 单位 = 企业。比如「××建筑劳务有限公司」，是项目里面的一层分组。

同一家公司可能在两个项目下都有人，这时它会分别在两个项目里各列一次，不会串在一起。

切换项目

  • 点右上角项目切换器（在「数据管理」左边）→ 选一个项目，台账立刻只显示这个项目的人；
  • 选「全部项目」可以一次看所有工地的人，此时列表按 项目 → 单位 两级分组；
  • 只选某一个项目时，仍按「所属单位」分组；
  • 切换器的选择会记住，下次打开还停在你上次看的项目。

新建 / 管理项目

两种入口，都能到「管理项目」：项目切换器 →「管理项目」，或 设置 →「工程项目」区块。每个项目可以：

登记与改归属

  • 在某个项目下登记，记录会自动带上当前项目；「所属单位」可用项目默认值预填，也能当场改；
  • 录错了项目不用删了重录——进编辑页改「所属项目」即可。

到期提醒看哪些证

提醒口径是固定的，不用你设置：

  • 当前项目的人员证（特种作业人员 / 管理人员）；
  • 全部企业级安全生产许可证（许可证按企业存、跟工地无关，任何时候都该提醒）；
  • 如果别的项目也有快到期的证，会补一句「（其它项目还有 N 张即将到期）」，避免你只看当前项目而漏掉。
一句话：人在项目下、证在企业下。人员证跟着项目走，许可证跟着公司走—— 这样切到哪个工地，看到的都是这个工地该管的人，而不会漏掉公司的许可证。

五、拍照识别，登记一张证件（最常用）

  1. 点底部标签，选对类型（例如登记一个电工，就点「特种作业人员」）。
  2. 点「拍照识别」。
  3. 对准证件 拍正、拍清晰：证件放平、光线充足、四角完整、别反光。
  4. App 在本机自动识别，几秒后把姓名、证号、工种、发证机关、有效期填进表单。
  5. 核对一下识别结果（尤其证号与有效期），有错直接点输入框手改。
  6. 点「保存登记」。
三个提效小技巧：
  • 可以从相册选已有的证件照片：点「拍照识别」后选「从相册选择」；
  • 一次可以选多张，走「批量识别」连续登记，适合新工人集中进场；
  • 拍错台账标签也没关系——识别出属于其它类别时会自动跳到对应台账登记；批量识别里混进其它类别的证件，也会在本批处理完后自动归类登记。
App 会先"整理"一遍识别结果，再填进表单：
  • 工种被换行截断会自动接上：证件上印成「…安装拆卸工（塔式起」换行「重机）」时，会补成完整工种，而不是只截一半；
  • 明显读错的日期不会写进台账：像「5 月 38 日」「0 月 42 日」这种不存在的日期，一律不采纳， 改用证件自带的年限规律推算；推不出来就留空让你手动补——不会拿一个"看着正常其实不对"的日期糊弄过去；
  • 所以偶尔会看到某个日期是空的。空着比填错安全——到期提醒靠这个日期，填错比留空更危险。

六、手写登记（识别不准时用）

如果照片太模糊识别不出来，直接在登记区逐项填写：姓名、证件类型/工种、证号、所属单位、发证机关、初次领证日期、有效期至、备注，然后点「保存登记」。

证件类型 / 工种支持 多选：展开「作业类别」后勾选多个「操作项目」，选中项会用 / 分隔，例如：

建筑架子工（普通脚手架）/ 电工作业（低压电工作业）

七、联网查询补全（验真 + 自动补全）

这是最省心、也最准的功能。在记录详情页（或新建登记后）点「联网查询补全」，App 会自动分流：

证件类型App 的行为你要做什么
住建部证（普通证号）直连住建部官网查询接口，补全权威信息等提示即可
应急部证（证号 T 开头）自动打开官方查询页，自动填表、自动识别验证码、自动提交并回填不要手动操作页面，等几秒
安全生产许可证先按证书编号查；查不到时自动换「企业名称」再查一次确保编号或企业名至少一个正确
联网查询需要手机能上网。它是「锦上添花」——识别不出来或想确认真伪时用它最靠谱。 想让它每次识别后自动查一遍，到设置里打开「识别后自动联网查询住建部证件信息」（默认关闭，需联网）。 关着的时候，手动点「联网查询补全」按钮一样能用。

八、查看 / 修改 / 删除一条记录

  • 查看：在台账列表点一下某条记录，进入详情/编辑页；长按可直接预览全部字段。
  • 修改：改完点「保存修改」。若记录已被删除会明确提示，不会假装保存成功。
  • 删除：编辑页右上角删除图标，会二次确认（删除不可恢复）。
  • 退场：人员的「已退场」开关用于区分"离场但留档"。

九、搜索与状态筛选

先确认你在哪个项目下（看左上角小字）——搜索和筛选都只在当前项目范围内生效。 找不到人时，先切到「全部项目」再看一眼。

  • 搜索：列表上方搜索框，输入姓名 / 证号 / 单位 / 工种，快速定位；
  • 状态筛选：全部 / 正常 / 即将到期 / 已过期 / 已退场；
  • 按单位分组：看单个项目时，台账按所属单位折叠展示；看「全部项目」时，按 项目 → 单位 两级分组（项目层是深绿、单位层是品牌绿）。

在「数据管理」页顶部的数据概览里，点「已过期 / 即将到期 / 已退场」的数字，可以直接跳到特种作业人员台账的对应分类。 注意概览的数字是整个台账（全部项目）的口径，与当前项目无关。

十、导出 Excel 台账

  1. 点右上角「数据管理」；
  2. 在「Excel 台账导出」里点要导出的类型（特种作业人员 / 安全生产许可证 / 管理人员）；
  3. 人员类台账会让你选导出范围：当前项目（默认，跟随你进来时看的是哪个项目）或 全部项目；
  4. 选择用微信、邮件等方式把文件发出去（也可存到「文件」App）。
  • 人员类台账的导出文件里带一列「所属项目」，按项目导出时文件名也会带上项目名，多个工地不会混淆；
  • 安全生产许可证永远整表导出——它是企业级的、没有项目维度，所以不受范围选择影响。

同一页还能「导出识别日志」：包含每次识别的耗时、行数、结果摘要，出问题时把这个文件发给技术人员即可定位。

十一、证件照片归档

每登记成功一张证件，它的照片会自动按分类归档，与台账记录对应。

  • 查看 / 删除：设置 →「证件文件管理」，可浏览、预览、删除已归档照片；
  • 导出到相册：在文件管理里点导出图标；
  • 照片默认保存到系统相册的「证件归档」目录，检查时可直接从相册调取。

十二、备份 / 恢复数据（防丢失）

  1. 点右上角「数据管理」；
  2. 「备份数据库」→ 生成一个 .db 备份文件，发到微信/网盘存好；
  3. 换手机或误删时，用「从备份恢复数据库」找回全部数据。
强烈建议：每周备份一次，或每次集中录入后备份一次。备份文件包含全部台账与设置，可跨设备迁移。 恢复时会先校验备份文件是否为完整数据库、是否含必需数据表，选错文件会明确报错并保留原数据，不会把现有台账弄丢。
  • 备份是整库口径：一次备份包含全部项目的数据，不用挨个项目导一遍；
  • 恢复后立刻生效：恢复完成后台账会自己刷新，不用重启 App（旧版本要杀进程重开才看得到）；
  • 如果备份来自另一台手机（项目完全不同），恢复后 App 会自动切到一个可用的项目，不会出现"恢复成功但台账是空的"——遇到空列表先检查左上角当前项目。

十四、常见问题（FAQ）

Q1：拍照识别不准 / 识别不出来？
证件放平、光线充足、别反光、四角拍全；确认设置里「识别结果缓存」是开着的（提速用）；还不行就手改，或点「联网查询补全」用官方数据。
Q2：证号 T 开头，联网补全跳到了网页？
正常。T 开头是应急管理部的证，App 会自动打开官方查询页全自动查询，不要手动操作，等它自己出结果回填。
Q3：一个证号对应多种工种怎么填？
在「证件类型 / 工种」下拉里展开作业类别，勾选多个操作项目，选中项会用 / 分隔显示，保存后一并入库。
Q4：怎么快速找到快过期的证？
台账列表橙色=即将到期、红色=已过期；或点「状态筛选 → 即将到期 / 已过期」只看这两类，定期扫一遍即可。
Q5：数据会不会丢？
数据存在手机本地，App 不会上传。请养成定期「数据管理 → 备份数据库」的习惯，把备份文件发到微信/网盘。卸载 App 会一并清除本地数据，卸载前记得先备份。
Q6：联网查询失败或查询不到？
检查网络；核对证号/姓名/企业名称是否与证件一致；政府网站偶有维护，稍后再试。识别与台账功能不受影响。
Q7：录进去的人不见了 / 台账是空的？
九成是当前项目不对——看左上角那行小字是哪个工地。点右上角项目切换器切到对应的项目，或选「全部项目」一次看全部。数据没有丢，只是被项目过滤掉了。
Q8：识别出来工种空着、或某个日期空着，是坏了吗？
不是坏了，是 App 故意留空。工种被换行截断时会自动接回完整名称；如果接不回来就不硬猜。日期同理—— 识别出的日期如果不合法（例如"5 月 38 日"），App 不会写进台账，改用证件年限规律推算，推不出来就留空等你手填。 空着比填错安全：到期提醒靠这个日期，填错比留空更危险。手动补上即可。
Q9：手上好几个工地，要装好几个 App 吗？
不用。一个 App 就能管多个项目，台账互相独立：右上角项目切换器切换，或进「管理项目」新建。详见第四节。

十五、给首次使用者的 5 条建议

  1. 先把工地建好：项目切换器 →「管理项目」→ 新建，并设好这个项目的默认单位；
  2. 再拍 1 张证试试，熟悉识别与保存的流程；
  3. 录入后点一次「联网查询补全」，确认证号真实有效，顺便把权威字段补齐；
  4. 每周或每次批量录入后，备份一次数据库；
  5. 用「状态筛选」定期扫一遍「即将到期 / 已过期」，把隐患提前消掉。
