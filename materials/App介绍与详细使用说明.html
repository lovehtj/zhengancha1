一这个 App 是干什么的

在工地现场，有三类证件必须有效、不能过期：

  • 特种作业人员证——电工、焊工、架子工、塔吊司机、高处作业等人员的证；
  • 安全生产许可证——企业施工的"营业执照"之一；
  • 安全生产管理人员证——安全员、项目负责人等人的证。

证件一旦过期或失效，属于重大事故隐患，可能被处罚。这个 App 就是帮你：

  • 拍照就能录入：拍一张证件照片，自动识别出姓名、证号、工种、发证机关、有效期，不用手打；
  • 联网查真伪：一键连接政府官网，核对证件是否真实、是否在有效期内；
  • 到期自动提醒：快到期、已过期的证件，列表里用颜色标出来；
  • 多个工地分开管：一个 App 管好几个工程项目，切一下只看这个工地的人，互不干扰；
  • 一键导出：把台账导成 Excel，方便上报、打印、迎检。
一句话：拍照存证、联网验真、到期提醒、导出报表。

二谁适合用

  • 施工项目部的 安全员、资料员——录入、台账、迎检一个人搞定；
  • 监理单位现场核验人员——拍张照就知道证真不真、过没过期；
  • 需要定期核查施工方证件是否有效的 项目管理人员 / 项目经理——一键导出报表。

五多个工程项目怎么管

一个 App 可以同时管好几个工地，台账彼此分开、互不干扰。先分清两个词：

  • 项目 = 工地。比如「滨江路项目」「中心医院项目」，是要分开管的；
  • 单位 = 企业。比如「××建筑劳务有限公司」，是项目里面的一层分组。

同一家公司可能在两个项目下都有人，这时它会分别在两个项目里各列一次，不会串在一起。

切换项目

  • 点右上角项目切换器（在「数据管理」左边）→ 选一个项目，台账立刻只显示这个项目的人；
  • 选「全部项目」可以一次看所有工地的人，此时列表按 项目 → 单位 两级分组；
  • 只选某一个项目时，仍按「所属单位」分组；切换器的选择会记住，下次打开还停在你上次看的项目。

新建 / 管理项目（项目切换器 →「管理项目」，或 设置 →「工程项目」区块）

操作作用
新建加一个工地；建议名字写全，导出文件名会带上它
重命名项目名写错了随时改（台账里的归属不会丢）
设置默认单位这个工地常驻的公司名；登记人员时会自动预填「所属单位」，仍可手动改

归档 / 恢复工地完工先归档，切换器里不再打扰你；以后要查再「恢复」出来，数据一直在

登记与改归属：在某个项目下登记，记录会自动带上当前项目，「所属单位」可用项目默认值预填、也能当场改； 录错了项目不用删了重录——进编辑页改「所属项目」即可。

到期提醒看哪些证（口径固定，不用设置）：当前项目的人员证 ＋ 全部企业级安全生产许可证。 许可证按企业存、与工地无关，任何时候都该提醒；如果别的项目也有快到期的证，会补一句 「（其它项目还有 N 张即将到期）」，避免你只看当前项目而漏掉。

一句话：人在项目下、证在企业下。人员证跟着项目走，许可证跟着公司走——这样切到哪个工地，看到的都是这个工地该管的人，而不会漏掉公司的许可证。

六拍照识别，登记一张证件（最常用）

  1. 点底部标签，选对类型（比如登记一个电工，就点「特种作业人员」）。
  2. 点「拍照识别」。
  3. 对准证件拍正、拍清晰：证件放平、光线充足、四角完整、避免反光。
  4. App 会在本机自动识别，几秒后把姓名、证号、工种、发证机关、有效期填到表单里。
  5. 核对识别结果（尤其证号与有效期），有错直接点输入框手改。
  6. 点「保存登记」。
三个提效技巧：
  • 可以从相册选已有照片：点「拍照识别」后选「从相册选择」；
  • 一次可选多张走「批量识别」，适合新工人集中进场；
  • 拍错台账标签也没关系——识别出属于其它类别时会自动跳到对应台账登记。
App 会先"整理"一遍识别结果，再填进表单：
  • 工种被换行截断会自动接上：证件上印成「…安装拆卸工（塔式起」换行「重机）」时，会补成完整工种，而不是只截一半；
  • 明显读错的日期不会写进台账：像「5 月 38 日」「0 月 42 日」这种不存在的日期一律不采纳， 改用证件自带的年限规律推算；推不出来就留空让你手动补——不会拿一个"看着正常其实不对"的日期糊弄过去；
  • 所以偶尔会看到某个日期是空的。空着比填错安全——到期提醒靠这个日期，填错比留空更危险。

七手写登记（识别不准时用）

照片太模糊识别不出来时，直接在登记区逐项填写：姓名、证件类型 / 工种、证号、所属单位、发证机关、初次领证日期、有效期至、备注，然后点「保存登记」。

「证件类型 / 工种」支持多选：展开「作业类别」后勾选多个「操作项目」，选中项会自动用 / 分隔，例如：

建筑架子工（普通脚手架）/ 电工作业（低压电工作业）

八联网查询补全（验真 + 自动补全）

这是最省心、也最准的功能。在记录详情页（或新建登记后）点「联网查询补全」，App 会自动按证件类型分流：

证件类型App 的行为你要做什么
住建部证（普通证号）直连住建部官网查询接口，补全权威信息等提示即可
应急部证（证号 T 开头）自动打开官方查询页，自动填表、自动识别验证码、自动提交并回填不要手动操作页面，等几秒
安全生产许可证先按证书编号查；查不到时自动换「企业名称」再查一次确保编号或企业名至少一个正确
联网查询需要手机能上网。它是"锦上添花"——识别不出来或想确认真伪时用它最靠谱。 想让它每次识别后自动查一遍，到设置里打开「识别后自动联网查询住建部证件信息」（默认关闭，需联网）。 关着的时候，手动点「联网查询补全」按钮一样能用。

九查看 / 修改 / 删除一条记录

  • 查看：在台账列表点一下某条记录进入编辑页；长按可直接预览全部字段。
  • 修改：改完点「保存修改」。若该记录已被删除，会明确提示保存失败，不会假装成功。
  • 删除：编辑页右上角删除图标，会二次确认（删除不可恢复）。
  • 退场标记：「已退场」开关用于区分"离场但需留档"的记录。

十搜索与状态筛选

先确认你在哪个项目下（看左上角小字）——搜索和筛选都只在当前项目范围内生效。找不到人时，先切到「全部项目」再看一眼。

  • 搜索：列表上方搜索框，输入姓名 / 证号 / 单位 / 工种快速定位；
  • 状态筛选：全部 / 正常 / 即将到期 / 已过期 / 已退场；
  • 按单位分组：看单个项目时按所属单位折叠；看「全部项目」时按 项目 → 单位 两级分组（项目层深绿、单位层品牌绿）。

在「数据管理」页顶部数据概览里，点「已过期 / 即将到期 / 已退场」的数字，可直接跳到特种作业人员台账的对应分类。 注意概览数字是整个台账（全部项目）的口径，与当前项目无关。

十一导出 Excel 台账

  1. 点右上角「数据管理」；
  2. 在「Excel 台账导出」里点要导出的类型（特种作业人员 / 安全生产许可证 / 管理人员）；
  3. 人员类台账会让你选导出范围：当前项目（默认）或 全部项目；
  4. 选择用微信、邮件等方式把文件发出去（或存到「文件」App）。
  • 人员类台账的导出文件带一列「所属项目」，按项目导出时文件名也会带上项目名；
  • 安全生产许可证永远整表导出——它是企业级的、没有项目维度。

同一页还可「导出识别日志」：包含每次识别的耗时、行数与结果摘要，遇到识别问题把该文件发给技术人员即可定位。

十二证件照片归档

每登记成功一张证件，照片会自动按分类归档，与台账记录一一对应。

  • 查看 / 删除：设置 →「证件文件管理」，可浏览、预览、删除已归档照片；
  • 导出到相册：在文件管理里点导出图标；
  • 照片保存到系统相册的「证件归档」目录，检查时可直接从相册调取。

十三备份 / 恢复数据（防丢失）

  1. 点右上角「数据管理」；
  2. 点「备份数据库」→ 生成一个 .db 备份文件，发到微信 / 网盘存好；
  3. 换手机或误删时，用「从备份恢复数据库」找回全部数据。
强烈建议：每周备份一次，或每次集中录入后备份一次。备份文件包含全部台账与设置，可跨设备迁移。 恢复时会先校验备份文件是否为完整数据库、是否含必需数据表；选错文件会明确报错并保留原有数据，不会破坏现有台账。
  • 备份是整库口径：一次备份包含全部项目的数据，不用挨个项目导一遍；
  • 恢复后立刻生效：恢复完成后台账会自己刷新，不用重启 App；
  • 如果备份来自另一台手机（项目完全不同），恢复后 App 会自动切到一个可用的项目，不会出现"恢复成功但台账是空的"——遇到空列表先检查左上角当前项目。
注意：卸载 App 会一并清除本地数据。卸载或换机前请务必先做一次备份。

十五常见问题（FAQ）

Q1：拍照识别不准 / 识别不出来？

证件放平、光线充足、别反光、四角拍全；确认设置里「识别结果缓存」处于开启状态（提速用）；仍然不行就直接手改，或点「联网查询补全」用官方数据覆盖。

Q2：证号是 T 开头，点联网补全后跳到网页了，正常吗？

正常。T 开头是应急管理部的证，App 会自动打开官方查询页并全自动查询，不要手动操作，等几秒结果会自己回填。

Q3：一个证号对应多种工种怎么办？

支持多选：在「证件类型 / 工种」下拉里展开作业类别，勾选多个操作项目，选中项会自动用 / 分隔保存。

Q4：怎么知道哪个证件快到期了？

台账列表里橙色=即将到期、红色=已过期、黄色=已退场、绿色=正常；也可以用「状态筛选」只看其中一类，定期扫一遍。

Q5：数据会不会丢？

数据存在手机本地，App 不会上传。建议定期「数据管理 → 备份数据库」，把备份文件发到微信 / 网盘。卸载 App 会清除本地数据，卸载前请先备份。

Q6：联网查询失败 / 提示查询不到？

先检查手机网络；再核对证号、姓名、企业名称是否与证件一致（联网查询按证号或企业名称精确匹配）；政府网站偶有维护时段，稍后再试。识别与台账功能不受影响。

Q7：录进去的人不见了 / 台账是空的？

九成是当前项目不对——看左上角那行小字是哪个工地。点右上角项目切换器切到对应的项目，或选「全部项目」一次看全部。数据没有丢，只是被项目过滤掉了。

Q8：识别出来工种空着、或某个日期空着，是坏了吗？

不是坏了，是 App 故意留空。工种被换行截断时会自动接回完整名称，接不回来就不硬猜；日期同理——识别出的日期如果不合法（例如"5 月 38 日"），App 不会写进台账，改用证件年限规律推算，推不出来就留空等你手填。空着比填错安全：到期提醒靠这个日期。手动补上即可。

Q9：手上好几个工地，要装好几个 App 吗？

不用。一个 App 就能管多个项目，台账互相独立：右上角项目切换器切换，或进「管理项目」新建。详见第五节。

十六给首次使用者的 5 条建议

  1. 先把工地建好：项目切换器 →「管理项目」→ 新建，并设好这个项目的默认单位。

  3. 录入后点一次「联网查询补全」，确认证号真实有效，顺便补齐权威字段。
  4. 每周或每次批量录入后，备份一次数据库。
  5. 用「状态筛选」定期扫一遍「即将到期 / 已过期」，把隐患提前消掉。

十七隐私与数据安全

数据类型App 的实际行为
